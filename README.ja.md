# アパレルCAD マニュアル

> ### 📘 マニュアル：**https://kadoya2005.github.io/apparel-cad-manual/**

**アパレルCAD** は、Illustrator と同じ操作で服の型紙を引き、直し、ほかの型紙CAD へ渡せる、ブラウザで動く試作アプリです。

- 型紙の線に役割（輪郭・縫い線・ダーツ・布目線・ノッチ）を付けられる
- 切り開き（パターン展開）：タイトスカートを開いてフレアスカートにできる
- AAMA DXF（型紙データの業界標準）で書き出せる
